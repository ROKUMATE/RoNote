# RoNote

RoNote turns one documentation page or a printed PDF into an editable study doc for IT and CS students. The source is reproduced word for word, with code blocks kept byte-identical and nothing AI-added. Students highlight it, write notes beside it and run its code blocks. Links to other pages on the same site can be imported with a click.

Status: pre-alpha

## Setup

Not ready yet. After cloning, run `make setup` to install the commit message hook.
